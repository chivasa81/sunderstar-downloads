# SUNDERSTAR for Android

An Iron Daydream Works playable campaign prototype.

This repository distributes signed APKs and checksums only. Game source and signing keys are not stored here.

Android 8.0+ with a current system WebView. Offline landscape play, multi-touch controls, 16 alternating ground/space mission configurations, and the supplied Velocity Breach score.

Download the APK from Releases, open it on your Android phone, and install. If prompted, allow that browser or file manager to install this app.

Package: com.irondaydreamworks.sunderstar. This prototype has automated checks but has not been physically phone-tested.
